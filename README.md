# SIMUDA - Sistem Informasi Manajemen Muda
Sistem Informasi Manajemen berbasis web untuk mendukung digitalisasi pendidikan di SMK Muhammadiyah 2 Ajibarang.

---

## 🚀 Tentang SIMUDA
**SIMUDA** adalah platform manajemen sekolah berbasis web & database yang dibangun untuk mempermudah administrasi akademik, keuangan, dan evaluasi siswa. Sistem ini dirancang oleh **Ibnu Syaebatul Risky**, siswa jurusan RPL (Rekayasa Perangkat Lunak), SMK Muhammadiyah 2 Ajibarang.

---

## 🎯 Fitur Utama

| Fitur                  | Deskripsi                                                                 |
|------------------------|--------------------------------------------------------------------------|
| 👨‍🏫 Multi-Login         | Akses berbeda untuk Admin, Guru, dan Siswa                               |
| 📝 Penilaian Siswa      | Input nilai Harian, UTS, UAS, hingga cetak raport                        |
| 🧪 E-Ujian               | Ujian online (harian, praktik, semester)                                |
| 💰 Manajemen SPP        | Tagihan bulanan, status pembayaran, dan histori                         |
| 🚨 Poin Pelanggaran     | Sistem poin pelanggaran dengan level SP1, SP2, hingga DO                |
| 📚 Perpustakaan Digital | Data buku, peminjaman, pengembalian                                     |
| 📊 Laporan Keuangan     | Modul pemasukan-pengeluaran sekolah                                     |
| 🎨 Tampilan Modern      | Light/Dark mode, animasi smooth, UI responsif dan elegan                |

---

## ⚙️ Teknologi yang Digunakan
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP Native
- **Database:** MySQL (phpMyAdmin)
- **Server:** XAMPP / Hosting Online
- **Versi Mobile (Planned):** APK Android berbasis WebView

## 🛠️ Cara Install di Localhost

```bash
1. Clone repo ini atau download sebagai ZIP
2. Letakkan folder di htdocs (XAMPP)
3. Import database dari file `simuda.sql` ke phpMyAdmin
4. Edit `config.php` sesuai username/password MySQL lokalmu
5. Jalankan di browser: http://localhost/simuda
